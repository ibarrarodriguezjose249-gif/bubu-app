# BÜBÜ para Expo Snack

Generada automáticamente desde `mobile/` con `python3 tools/generar_snack.py`. No edites aquí.

Para cargar una versión nueva **usa un Snack nuevo** (re-importar en uno existente crea copias "archivo 1.js" o duplica contenido):
1. https://snack.expo.dev (una sola pestaña) → Log in.
2. ⋮ junto a Project → Import files → arrastra **todos los .js excepto App.js**.
3. Pega el contenido de `App.js` y `package.json` de esta carpeta en los archivos del mismo nombre.
4. Save → abre en Expo Go con la misma cuenta.
